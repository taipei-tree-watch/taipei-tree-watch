# Taipei Tree Watch

公民回報的台北市病樹與移除樹木地圖。任何人都可以在地圖上標出一棵罹病、被移除或被移植的樹，記下現場公告或官方文件上寫的原因、樹被處理到什麼程度、以及作為存證的貼文連結。

這個網站的核心目標是找出褐根病（*Phellinus noxius*）的空間熱點。褐根病藉病根接觸與病根殘體搬運擴散，病死樹的殘根可在土中存活十年以上，因此疫情高度空間聚集：同一路段、同一公園、同一校園的樹木會接續死亡。現況是各單位各自處理、沒有跨單位的空間視角，一張公開的點位圖可以讓「這條街三年內死了七棵」這種模式浮現出來。

原因只照抄公告或官方文件，不由回報者推測；沒有公告時原因留空、點位照樣收。受保護樹木清冊作為參考圖層顯示，用來標記「這棵受保護樹木被移除了」，它們本身不是病樹。完整需求見 [docs/SPEC.md](docs/SPEC.md)，名詞定義見 [CONTEXT.md](CONTEXT.md)。
